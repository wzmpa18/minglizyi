## 二、按功能模块的参考基准

### 模块 1：紫微斗数排盘页

| 维度 | 内容 |
|------|------|
| 优先参考对象 | jishiyu（视觉） + ziwei（交互）+ suangua（布局） |
| 协议 | AGPL（仅视觉）/ MIT（交互逻辑） |
| 参考维度 | 圆盘布局、宫位信息层级、四化展示方式、宫位详情弹窗交互 |
| 禁止行为 | 直接复制圆盘 Canvas/SVG 代码、复制 CSS 类名、复制 DOM 结构 |

#### 页面整体布局结构（参考说明）

**来自 jishiyu 的布局参考（仅视觉观察）**：
- 页面采用上下结构，顶部为排盘信息栏（显示公历、农历、四柱干支），下方为紫微命盘主体
- 命盘主体为圆形布局，十二宫位沿圆周均匀分布，每个宫位包含：宫名、地支、主星、辅星、大限年龄范围
- 宫位之间用放射线分隔，中心区域为太极图或命宫标识
- 底部为四化飞星列表，按化禄、化权、化科、化忌分四行展示

**来自 ziwei 的布局参考**：
- 命盘采用 4x4 网格布局（CSS Grid），按地支方位排布十二宫：巳午未申为上行、辰酉为中行左右、卯戌为下行左右、寅丑子亥为底行
- 每个宫位卡片内信息层级为：宫名（顶部）→ 主星（带亮度色标）→ 辅星/杂曜 → 大限范围 → 宫干
- 星曜采用有色标签样式，不同亮度等级（庙旺得地利平陷）对应不同颜色深度
- 命主/身主标识和纳音五行信息在宫位中显示

**来自 suangua 的布局参考**：
- 紫微盘输入表单包含年、月、日、时辰选择器和性别选择
- 宫位展示采用表格形式，命宫/兄弟/夫妻等十二宫各占一行，展示宫干、宫支、主星、辅星、大限起止年龄
- 星曜亮度用文字标注（庙、旺、得、地、利、平、陷）

#### 关键交互逻辑（参考说明）

- 点击宫位卡片弹出宫位详情弹窗，展示该宫位的完整星曜分布、四化关联、大限流年信息
- 四化星用不同颜色区分（化禄绿色、化权蓝色、化科黄色、化忌红色），飞星路径用箭头连线表示
- 支持流年命盘叠加显示，当前流年宫位高亮标记
- 主星上 hover 显示星曜的简要说明（五行、阴阳、基本特质）

#### 核心信息的展示顺序

1. 命盘整体（十二宫环形布局）
2. 各宫主星分布（庙旺亮度标注）
3. 四化飞星（化禄、化权、化科、化忌的落宫与连线）
4. 命主身主标识
5. 五行局信息
6. 大限年龄标注
7. 点击宫位后展开的宫位详情

#### 页面整体布局结构（参考说明）

**来自 jishiyu 的布局参考（仅视觉观察）**：

- 排盘输入页包含日期选择器和出生时间选择
- 排盘结果页采用上下结构：顶部为出生信息，中部为四柱八字展示区，下部为十神、藏干、纳音、空亡等详细信息

- 八字排盘页面采用 Tab 切换结构：命盘、日主、运势、事业、婚姻、健康、财运、合婚共 8 个分析维度

- 日主 Tab 展示身强身弱判定结果，包含评分和详细分析

**来自 mystilight-8char 的布局参考**：
- Demo 页面的四柱展示采用横向排列，每柱为一个独立区块
- 天干和地支上下排列，天干在上、地支在下
- 藏干信息以小字显示在地支下方
- 十神标注在天干上方

#### 关键交互逻辑（参考说明）

- 排盘输入表单支持公历日期选择，自动换算农历，支持时间选择
- 四柱卡片支持 hover 显示详细信息（藏干、纳音、空亡、十神）
- 大运时间轴支持点击切换，点击某步大运后展示该大运的详细信息
- 十神关系以生克连线图展示，直观体现日干与其他天干的关系
- 空亡地支以特殊样式标注（如虚线边框或灰色底色）

#### 核心信息的展示顺序

1. 出生信息栏（公历日期、农历日期、性别）
2. 四柱八字展示（年柱、月柱、日柱、时柱）
3. 各柱详细信息（天干、地支、藏干、纳音、空亡）
4. 十神分析（日干与其他天干的关系）
5. 身强身弱判定（评分 + 详细分析）
6. 大运流年（起运年龄、大运时间轴）
7. 格局判定（正八格/特殊格局，主格局标签）

- 方剂库页面：搜索框 + 分类筛选 chip 按钮 + 方剂卡片网格，每张卡片含方剂名、分类标签、功效（截断显示）、出处
- 药材库页面：搜索框 + 药材卡片网格，每张卡片含药材名、品级标签（上中下品用不同颜色）、性味
- 方剂详情弹窗：方剂名 + 分类 + 组成列表（每味药材可点击跳转详情）+ 功效 + 主治 + 出处
- 药材详情弹窗：药材名 + 品级 + 性味 + 归经 + 功效 + 注意事项
- 辨证学习页面：症状输入区（文本输入 + 预设症状 chip）+ 症状标签展示区 + 查询按钮 + 结果展示区
- 结果展示区结构：免责声明栏 → 典籍对应证型列表（证型名 + 匹配度百分比）→ 典籍对应记载方剂列表（方剂名 + 匹配度 + 适用场景 + 出处）→ 底部免责声明

#### 关键交互逻辑（参考说明）

- 首页搜索框输入关键词回车后跳转到方剂库页面并执行搜索
- 导航栏按钮切换页面，首次进入时懒加载数据
- 分类筛选使用 chip 按钮，点击后前端过滤，支持"全部"重置
- 方剂详情弹窗中的药材条目可点击跳转到药材详情弹窗，实现知识交叉关联
- 辨证演示中，症状以 tag 标签展示，可逐个删除
- 查询按钮在请求中禁用，防止重复提交
- 所有页面和弹窗带 fadeIn 入场动画
- 首次使用显示知情同意弹窗（全屏遮罩 + 居中对话框），用户同意后方可进入
- 所有功能入口和结果展示区均标注"学习用途・非医疗建议"免责徽章

#### 核心信息的展示顺序

1. 首页：搜索入口 → 统计数据 → 功能入口卡片
2. 方剂库：搜索 → 分类筛选 → 方剂列表
3. 药材库：搜索 → 药材列表
4. 方剂详情：基本信息 → 组成 → 功效主治 → 出处
5. 药材详情：基本信息 → 性味归经 → 功效 → 注意事项
6. 辨证演示：症状输入 → 结果展示（免责声明 → 证型匹配 → 方剂推荐 → 免责声明）

## 三、颜色与视觉风格参考

### 参考来源：jishiyu（仅视觉观察）

- 主题色：红色系（#d12824），用于关键按钮、标题强调
- 排盘结果展示区以白色/浅灰背景为主，文字为深色
- 干支信息使用中国传统配色（天干红色系、地支蓝色系）
- 宫格/卡片使用圆角边框，简洁清晰

### 参考来源：ziwei（仅视觉观察）
