## 一、免责声明模板库

### 1.1 排盘结果免责栏（固定，不可关闭）

```
本内容仅供传统文化娱乐学习参考，不构成任何人生决策建议。
```

**使用场景**：
- 八字排盘结果页
- 紫微斗数排盘结果页
- 奇门遁甲排盘结果页
- 六爻排盘结果页
- 风水罗盘排盘结果页
- 所有命理工具的输出结果页

**展示规范**：
- 位置：页面底部固定浮层，始终可见
- 样式：浅灰色背景，字号小于正文，与正文有明显视觉区分
- 行为：不可关闭、不可折叠、不可滑动隐藏
- 字体颜色：使用次要文字色（如 `#999` 或 `text-muted`）

### 3.4 禁用词适用范围

- **前端展示文案**：所有页面中的静态文本、动态文本
- **后端返回文案**：API返回给前端的任何解读文本
- **推送通知文案**：Push消息、短信、邮件中的命理相关内容
- **分享文案**：用户分享时生成的默认文案
- **客服话术**：客服系统中与命理相关的自动回复
- **营销文案**：广告投放、落地页、宣传物料中的命理相关内容

### 3.5 合规审查机制

- **代码审查阶段**：CI/CD流水线中集成禁用词扫描脚本，每次提交自动检测
- **内容审核阶段**：运营后台发布内容前须经过禁用词自动过滤
- **定期巡检**：每月一次全量文案扫描，生成合规报告

## 附录：合规标注实施规范

### A.1 视觉规范

| 属性 | 规范值 |
|------|--------|
| 字体大小 | 12px - 13px |
| 字体颜色 | #999999 (次要文字色) |
| 背景颜色 | #F5F5F5 (浅灰底色) |
| 内边距 | 12px 16px |
| 圆角 | 4px (如为独立区块) |
| 图标 | 信息图标（info-circle），14px，与文字同色 |

### A.2 交互规范

- **固定免责栏**：不可关闭、不可折叠、不可滑动隐藏
- **流派说明**：可折叠/展开，默认展开
- **尾注文字**：始终可见，无需交互

### A.3 开发规范

- 所有免责声明文案须定义在统一的常量文件（如 `constants/disclaimers.ts`）中，避免硬编码
- 使用统一的免责栏组件（如 `<DisclaimerBar />`）保证全局一致性
- 流派说明使用统一组件（如 `<SchoolNote />`），通过 props 传入不同文案
- 禁用词过滤逻辑集成在 CI/CD 的 pre-commit hook 中
