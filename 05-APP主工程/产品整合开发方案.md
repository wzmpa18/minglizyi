## 1. 推荐产品架构

### 1.1 总体架构设计原则

本产品采用**前后端分离**架构，严格遵循宪法 v12.6 定义的 L1-L5 五层数据分层模型。前端负责展示与交互（L5），后端按职能拆分为多个独立服务层（L1-L4），各层之间通过 API 网关通信，保证高内聚、低耦合。

**核心设计原则**：

- **离线优先**：L1 核心排盘算法必须内置于客户端，不依赖网络即可完成排盘计算
- **协议隔离**：AGPL 协议代码仅做算法参考，不进入商用主版本代码库
- **合规前置**：所有命理/中医功能页面在 UI 层面即完成合规标注，不做后置打补丁
- **资产复用**：最大化复用已有开源算法资产，降低重复开发成本

### 1.3 各层职责定义

| 层级 | 名称 | 职责 | 部署位置 | 依赖关系 |
|------|------|------|----------|----------|
| L1 | 核心排盘算法层 | 八字/紫微/奇门/六爻/梅花/大六壬/小六壬/玄空飞星八大排盘算法，纯函数实现，无外部依赖 | 客户端内置 | 无外部依赖 |
| L2 | 内容服务层 | 用户管理、收藏/历史/分享、门派配置、数据同步、社区内容管理 | 云端服务器 | 调用 L3 数据，被 L5 调用 |
| L3 | 知识库与题库层 | 中药/方剂/穴位/典籍的结构化数据存储与检索 | 云端服务器 | 被 L2 和 L4 调用 |
| L4 | AI智能服务层 | 命理AI解读、中医AI问答、合盘分析、运势分析 | 云端服务器（LLM API） | 调用 L1 结果和 L3 数据，被 L5 调用 |
| L5 | 应用展示层 | 多端 UI 组件、交互流程、合规标注展示 | 客户端 | 调用 L2 和 L4 |

### 1.4 技术栈推荐

#### 前端技术栈

| 技术选型 | 推荐方案 | 备选方案 | 选型理由 |
|----------|----------|----------|----------|
| 跨平台框架 | React Native | Flutter | 生态成熟，与 Web 端共享逻辑层，L1 算法层用 TypeScript 可直接复用 |
| Web 前端 | React 18 + TypeScript | Vue 3 + TypeScript | 与 React Native 技术栈统一，社区资源丰富 |
| 状态管理 | Zustand / Redux Toolkit | MobX | 轻量级，适合离线优先场景 |
| UI 组件库 | 自研组件库 + Tamagui | Ant Design Mobile | 定制化排盘展示需求高，自研可控 |
| 图表可视化 | ECharts / D3.js | Recharts | 排盘命盘展示需要高度定制化渲染 |

#### 后端技术栈

| 技术选型 | 推荐方案 | 备选方案 | 选型理由 |
|----------|----------|----------|----------|
| 服务端框架 | Node.js (Express/Fastify) | Python (FastAPI) | 与前端 TypeScript 共享类型定义，L1 算法可同构运行 |
| API 网关 | Nginx + Kong | Traefik | 成熟稳定，支持限流/鉴权/日志 |
| 数据库 | PostgreSQL (生产) + SQLite (本地) | MySQL | SQLite 本地离线存储，PostgreSQL 云端高性能 |
| 缓存 | Redis | - | 会话管理、热点数据缓存 |
| 对象存储 | MinIO / 阿里云 OSS | 腾讯云 COS | 典籍文本、穴位图谱等静态资源存储 |
| AI 服务 | OpenAI API / 国内大模型 API | - | 命理解读和中医问答的 LLM 推理 |

| 技术选型 | 推荐方案 | 说明 |

### 2.4 合规标注体系

根据宪法 v12.6 第五编（57条合规红线），所有输出内容必须按以下规则标注：

| 内容类型 | 强制标注文本 | 标注位置 |
|----------|-------------|----------|
| 命理排盘结果 | 「传统文化娱乐参考，不构成人生决策建议」 | 页面底部固定栏 |
| 命理AI解读 | 「以下内容由AI生成，仅供传统文化娱乐参考，不构成人生决策建议」 | 解读内容顶部 |
| 中药信息 | 「传统文化科普记载，不构成医疗建议」 | 药品详情页顶部 |
| 方剂信息 | 「传统文化科普记载，不构成医疗建议。方剂使用须遵医嘱」 | 方剂详情页顶部 |
| 穴位信息 | 「传统文化科普记载，不构成医疗建议」 | 穴位详情页顶部 |
| 典籍内容 | 「古籍文献原文，仅供学术研究与文化科普参考」 | 典籍阅读页顶部 |

**禁止表述清单**（严格禁止在APP中出现）：

- 「算命」「改运」「化解」「消灾」「转运」等迷信词汇
- 确定性预测或承诺（如「你一定会发财」「今年必有大灾」）
- 疾病诊断、处方开具、疗效承诺、替代医疗建议
- 任何涉及医疗行为引导的表述

#### 5.3.3 体质与命理关联

| 关联维度 | 命理侧数据 | 中医侧数据 | 关联逻辑 |
