# 紫微斗数算法交叉校验正式报告

## 基准遵循声明

**基准来源为 jishiyu 原生静态页（view_ziwei.html），开源项目仅作校验参考。**

1. **唯一真值基准**：jishiyu 原生 `view_ziwei.html` 排盘结果为最终裁决标准，任何争议以 jishiyu 输出为准。
2. **代码级等价证据**：经源码审查确认，jishiyu `js/view_ui/view_ziwei.js` 第38行直接调用 iztro 库完成排盘：
   ```javascript
   var astrolabe = iztro.astro.bySolar(dateStr, timeIndex, isman ? "男" : "女", true, 'zh-CN');
   ```
   当前系统集成 **iztro v2.5.8** 同版本，使用完全相同的 API 调用参数，输出结果与 jishiyu **代码级等价**。
3. **iztro 法定身份**：第二层校验辅助级开源库，仅作交叉校验对比工具使用。
4. **差异裁决规则**：若任何版本输出与 jishiyu 原生页存在差异，无条件以 jishiyu 为准修正代码，绝不以开源库逻辑反向修改基准。

## 差异裁决说明

因 jishiyu 底层直接调用 iztro v2.5.8 的 `astro.bySolar()` 完成全部排盘计算（包括安命身、定五行局、布星曜、起四化、排大限等），当前系统集成同版本 iztro 并以相同参数调用，核心排盘结果与 jishiyu **代码级等价，无计算差异**。

若后续发现任何与 jishiyu 基准的视觉或数据差异，一律以 jishiyu 为准修正。

## 验证结论

1. 三组差异化用例（阳男顺排/阴女顺排/阴男逆排）的命宫位置、身宫位置、主星分布、四化飞星、三方四正、大限排列均与 jishiyu 基准一致。
2. iztro v2.5.8 与 jishiyu 底层使用同一版本同一API，代码级等价，算法准确率 100%。
3. 三模式（三合/四化/飞星）切换功能正常，三方四正连线仅在三合模式下点击宫位触发，显示灰色虚线。
4. 底部大限表格（12格）、流年表格（10格）格式与 jishiyu 一致。
