# 紫微斗数源码合规说明

## 一、UI层CSS合规声明

### 类名体系
紫微斗数页面（`src/app/yixue/ziwei/page.tsx`）**全部使用 Tailwind CSS 原子类**实现样式，不存在自定义CSS类名，不涉及任何jishiyu原生CSS类名复用问题。

**具体说明**：
- 页面所有样式通过 Tailwind 工具类（如 `flex`, `grid`, `bg-white`, `text-sm`, `rounded-lg` 等）实现
- 内联 `style` 属性仅用于动态颜色（如五行色、四化高亮色）
- **不包含任何jishiyu原生CSS类名**（如 `layui-*`, `zw-*`, `dayun-grid*`, `app-*` 等）
- 全局CSS中无紫微斗数专用自定义类，所有样式均为组件级Tailwind原子类

### 品牌色与五行色边界
- UI框架色：紫色 `#7B2FBE`（按钮、品牌高亮）使用Tailwind或内联style
- 命理内容色：五行色（金橙/水蓝/木绿/火红/土棕）通过内联style动态绑定，严格对应星曜五行属性
- 四化色：禄（绿）、权（蓝）、科（粉）、忌（红）独立于品牌色体系，不互相干扰

## 二、算法层基准来源声明

| 算法模块 | 来源 | 基准裁决权 | 备注 |
|---------|------|-----------|------|
| 紫微斗数排盘核心 | iztro v2.5.8（npm包） | 以jishiyu输出为唯一真值 | jishiyu底层直接调用iztro，代码级等价 |
| 安命身、定五行局 | iztro内部实现 | 以jishiyu输出为准 | 与jishiyu一致 |
| 布星曜、起四化 | iztro内部实现 | 以jishiyu输出为准 | 与jishiyu一致 |
| 排大限/流年 | iztro内部实现 | 以jishiyu输出为准 | 与jishiyu一致 |
| 三方四正判定 | 自行实现（地支三合/六合规则） | 以jishiyu输出为准 | 传统术数规则，非jishiyu独创 |
| 宫位天干 | 五虎遁规则 | 以jishiyu输出为准 | 传统术数规则 |

**核心原则**：
- jishiyu为唯一视觉和数据基准
- iztro作为第二层校验工具，因jishiyu自身使用iztro排盘，两者代码级等价
- 如发现任何与jishiyu基准不一致，无条件以jishiyu为准修正

## 三、净室开发确认

1. UI层：完全使用Tailwind CSS原子类+内联style独立实现，未复制jishiyu任何CSS源码（layui框架样式、zw-pan-container等专有类名均未使用）
2. 算法层：通过npm包引用iztro库（开源协议合规），核心排盘逻辑与jishiyu底层一致
3. 页面结构：参考jishiyu的信息架构（十二宫圆盘+底部表格），但使用React+Tailwind独立实现
4. 无任何直接复制jishiyu源码（HTML/CSS/JS）的行为
