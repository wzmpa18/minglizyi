# 净室开发确认说明

**项目名称**：言道（YanDao）传统文化学习平台
**技术栈**：Next.js 16 + TailwindCSS + shadcn/ui + ECharts
**开发日期**：2026年7月

## 净室开发确认

本人（TRAE 开发代理）在此确认以下事项：

### 1. 代码独立性
- 所有前端代码（HTML/CSS/JS/TSX）均为独立编写，未复制任何参考项目（jishiyu、TCM-Learning-Assistant、ziwei、suangua 等）的源代码
- 样式实现完全使用 TailwindCSS 类名，未拷贝参考项目的 CSS 文件内容
- 组件结构为独立设计，使用 React + TypeScript 自主实现

### 2. 视觉对标方式
- 仅对标参考项目的视觉效果、布局结构、交互流程
- 通过浏览器截图观察参考项目的外观，独立编写代码实现相同视觉效果
- 未使用任何"查看源代码"、"开发者工具复制"等方式获取参考项目的代码

### 3. 允许的修改范围（仅5项）
1. 配色体系：品牌色从 jishiyu 红色(#d12824)替换为 言道 紫色(#4F46E5)
2. 图标素材：全部替换为独立图标方案
3. 品牌信息：品牌名替换为"言道"，底部版权备案信息替换
4. 底层算法：接入自有算法库 @/algorithm-core，数据来自合规数据资产
5. 新增模块：全局首页、双层导航、社交广场、通讯录、消息中心、个人中心等独有模块

### 4. 算法与数据来源
- 命理算法来自 @/algorithm-core（基于公开经典命理文献独立实现）
- 中医数据来自自有合规数据资产
- 未使用任何参考项目的算法代码或数据文件

### 5. 开源协议合规
- 参考项目 jishiyu（AGPL-3.0）：仅作视觉和交互参考，未使用其源代码
- 参考项目 TCM-Learning-Assistant（MIT）：仅作 UI 布局参考，未复制其代码
- 本项目的第三方依赖全部使用 MIT/ISC/Apache 协议
- 未依赖任何 AGPL 协议组件

### 6. 免责声明
- 所有易学工具页面包含"以上内容由AI生成，仅供娱乐参考，请勿完全相信"声明
- 所有中医学习页面包含"仅供学习参考·不构成医疗建议"声明
- 所有 AI 生成内容标注"AI生成，仅供参考"
