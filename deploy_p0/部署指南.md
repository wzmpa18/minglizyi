# 言道APP P0首次公网部署指南

## 部署信息
- 服务器：腾讯云 82.156.228.87
- 部署目录：/var/www/yandao/web
- 运行环境：Linux + Nginx（纯静态站点，无需Node.js）
- 版本：P0-v1.0 (2026-07-30)
- 部署范围：首页 + 八字 + 梅花 + 小六壬 + 紫微 + 大六壬（共6个核心模块）

## 部署步骤

### 第1步：备份现有文件
```bash
cd /var/www/yandao
# 如果web目录已存在，完整备份
if [ -d web ]; then
    tar -czf backup_p0_before_20260730.tar.gz web/
    echo "备份完成: backup_p0_before_20260730.tar.gz"
fi
```

### 第2步：上传静态文件
将 `out/` 目录下所有文件上传到 `/var/www/yandao/web/`：
- 方式1（SFTP）：使用WinSCP/FileZilla连接82.156.228.87，将out目录内容上传至/var/www/yandao/web/
- 方式2（scp）：`scp -r out/* root@82.156.228.87:/var/www/yandao/web/`

确保目录结构为：
```
/var/www/yandao/web/
├── index.html              （首页）
├── favicon.ico
├── 404.html
├── images/                 （图标资源）
├── _next/                  （Next.js静态资源）
└── yixue/
    ├── bazi/index.html     （八字）
    ├── meihua/index.html   （梅花）
    ├── xiaoliuren/index.html（小六壬）
    ├── ziwei/index.html    （紫微）
    └── daliuren/index.html （大六壬）
```

### 第3步：配置Nginx
将 `nginx_yandao.conf` 上传到 `/etc/nginx/conf.d/yandao.conf`，然后：
```bash
# 测试配置
nginx -t

# 平滑重启
nginx -s reload
# 或
systemctl reload nginx
```

### 第4步：验证部署
```bash
# 检查HTTP状态
curl -I http://82.156.228.87/
curl -I http://82.156.228.87/yixue/ziwei/
curl -I http://82.156.228.87/yixue/daliuren/

# 公网访问验证（浏览器打开）
# http://82.156.228.87/
```

## 回滚方案
如部署后出现问题：
```bash
cd /var/www/yandao
rm -rf web
tar -xzf backup_p0_before_20260730.tar.gz
nginx -s reload
```
