## 一、系统盘快照（性价比最高的备份）

### 1.1 创建自动快照策略
**路径**：控制台 → 轻量应用服务器 → 快照 → 自动快照策略 → 新建

| 配置项 | 建议值 |
|--------|--------|
| 策略名称 | `yandao-daily-snapshot` |
| 执行时间 | 每日 03:00（与备份脚本错开1小时） |
| 保留时间 | 7 天 |
| 关联实例 | `lhins-4ak6ifwg`（82.156.228.87） |

### 1.2 跨地域复制快照（北京 → 上海）
**路径**：控制台 → 轻量应用服务器 → 快照 → 选择快照 → 跨地域复制

| 配置项 | 建议值 |
|--------|--------|
| 源地域 | 北京（ap-beijing） |
| 目标地域 | 上海（ap-shanghai） |
| 复制频率 | 每周一次（手动或等后续自动策略支持） |

> 轻量服务器跨地域复制目前仅支持手动单次操作，建议每周一执行一次。

## 二、COS 对象存储（文件级异地容灾）

### 2.1 开通 COS
**路径**：控制台 → 对象存储 → 存储桶列表 → 创建存储桶

| 配置项 | 建议值 |
|--------|--------|
| 名称 | `yandaoguoxue-backup` |
| 地域 | 上海（ap-shanghai，与北京异地域） |
| 访问权限 | 私有读写 |

### 2.2 开启版本控制
**路径**：存储桶 → 容错容灾管理 → 版本控制 → 开启

- 文件被覆盖/删除后，历史版本仍可恢复

### 2.3 开启回收站
**路径**：存储桶 → 容错容灾管理 → 回收站 → 开启

| 配置项 | 建议值 |
|--------|--------|
| 保留天数 | 30 天 |

### 2.4 配置生命周期规则
**路径**：存储桶 → 容错容灾管理 → 生命周期

| 规则 | 配置 |
|------|------|
| 历史版本 | 30 天后自动删除 |
| 删除标记 | 30 天后自动清理 |

### 2.5 获取 API 密钥（用于服务器 coscmd 同步）
**路径**：控制台 → 访问管理 → API 密钥管理 → 创建密钥

拿到 SecretId + SecretKey 后，在服务器执行：
```bash
coscmd config -a <SecretId> -s <SecretKey> -b yandaoguoxue-backup -r ap-shanghai
```

## 三、账号安全加固

### 3.1 绑定多个负责人手机号
**路径**：控制台 → 账号信息 → 安全设置 → 联系手机

- 绑定至少 2 个手机号（吴志民 + 备用负责人）

### 3.2 开启 MFA 二次验证
**路径**：控制台 → 账号信息 → 安全设置 → MFA 设备 → 绑定

- 推荐：微信扫码绑定虚拟 MFA

### 3.3 开启欠费告警
**路径**：控制台 → 费用中心 → 账户告警

| 告警类型 | 阈值 |
|----------|------|
| 账户余额不足 | 余额 < 50 元 |
| 后付费账单 | 单日费用 > 100 元 |

### 3.4 开启异常登录告警
**路径**：控制台 → 账号信息 → 安全设置 → 登录保护

- 开启异地登录告警
- 开启操作保护（关键操作需二次验证）

### 3.5 开启操作审计日志（CloudAudit）
**路径**：控制台 → 操作审计 → 跟踪集 → 创建

- 保存到 COS（上海桶），保留 90 天
- 所有 API 操作自动记录，不可删除
