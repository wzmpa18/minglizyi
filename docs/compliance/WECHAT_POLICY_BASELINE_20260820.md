# 微信小程序政策基线 WECHAT_POLICY_BASELINE_20260820

> 言道国学 · 微信小程序「AI学习工具 + 学习空间」
> 基线日期：2026-08-20 ｜ 调研来源：微信官方文档 + 开放社区 + 国家法规
> 状态：**调研基线已建立，标注【后台确认】项须在 mp.weixin.qq.com 后台正式核实后方可开发**

---

## 0. 产品定位（已锁定）

微信小程序版本定位：**「AI学习工具 + AI资料变题库 + 团队学习空间」**，对外口径为「传统文化与中医经典学习工具」。

**永久禁止出现在微信端的功能**（服务端 PLATFORM_FEATURE_MATRIX 强制，不可通过远程配置打开）：
算命、预测、八字排盘、紫微排盘、奇门排盘、六爻占卜、大六壬、塔罗、占星预测、命理咨询。

---

## 1. 主体资格与类目

| 项 | 基线结论 | 来源 |
|---|---|---|
| AI问答/深度合成类目 | 需企业主体 + 深度合成类目（如「深度合成-AI问答」）+ 算法备案资料 | 微信开放社区 |
| 教育-在线教育类 | 通常需企业/民办非企业/事业单位主体；个人主体不适合经营性卖课 | 微信类目文档 |
| 社交-社区/论坛类目 | 需提供《非经营性互联网信息服务备案核准》（ICP备案）或机构信用代码证 | https://developers.weixin.qq.com/miniprogram/product/material/ |
| 个人主体可用范围 | 部分工具类目；无法覆盖本项目AI+学习空间核心形态 | 第三方总结（保守） |

**本项目决策**：
- 优先评估类目：`工具-智能助手` / `深度合成-AI问答` +（如做公开社区）`社交-社区/论坛`
- 若学习空间仅做私密团队协作（非公开广场/论坛），优先按工具类目申报，避开社交类目门槛
- 【后台确认】当前主体在「设置-基本设置-服务类目」中实际可选的类目清单与资质上传要求

## 2. 封建迷信内容红线

- 小程序名称/简介/页面出现算命、占卜、看相、测运势等表述 → 直接驳回风险（审核驳回规则文档：https://developers.weixin.qq.com/miniprogram/product/reject.html）
- 《互联网信息服务管理办法》第十五条：禁止传播宣扬封建迷信的信息
- **执行**：PLATFORM_FEATURE_MATRIX 中 bazi/ziwei/qimen/liuyao/daliuren/xiaoliuren/meihua/tarot/astrology/hehun/fortuneConsult 在 wechat 平台全部 OFF（服务端 403，非仅隐藏按钮）
- 前端文案禁用词库：算命、预测、吉凶、开运、化解、改运、看相、测运

---

## 3. 聊天文件能力（微信学习资料入口）

- `wx.chooseMessageFile`：基础库 2.5.0+ 支持；多端应用需改用 `wx.miniapp.chooseFile`
- 无特殊类目资质要求，但**必须在《用户隐私保护指引》中声明文件选择处理行为**，否则可能被驳回
- 禁止以「获取聊天记录」为卖点（敏感个人信息）
- **本项目决策**：支持 PDF/DOC/DOCX/TXT/图片，从聊天会话选择文件 → 预览 → 用户确认合法学习用途 → AI解析
- 【后台确认】基础库最低版本设置（建议 ≥2.5.0，实际以后台「开发设置-基础库最低版本」为准）

---

## 4. UGC 内容安全（动态/评论/学习空间讨论）

强制要求：
1. 文本内容：服务端调用 `msgSecCheck`（https://developers.weixin.qq.com/miniprogram/dev/server/API/sec-center/sec-check/api_msgseccheck）
2. 图片内容：`imgSecCheck` / `mediaCheckAsync` 异步审核
3. 举报入口：UGC 页面必须有真实有效的举报按钮 + 后台处理流程
4. 用户协议、社区规范、联系方式必须齐备

**本项目决策**：学习空间内的讨论/公告/笔记若开放 UGC，全部走服务端内容安全检测后再落库；检测失败默认拒绝展示。

---

## 5. AI 生成内容监管

- 涉及AI问答/深度合成 → 企业主体 + 深度合成类目 + 算法备案资料（云开发可生成备案材料）
- 《人工智能生成合成内容标识办法》（2025-09-01 施行）：AI生成内容需显著标识
- 算法备案入口：https://beian.cac.gov.cn
- **本项目决策**：所有AI生成内容（知识点、题目、解析）统一标注「AI生成，仅供参考」；AI中医内容附加「不构成医学诊断、治疗依据」

## 6. 医疗健康边界（中医经典自学）

| 允许（学习教育口径） | 禁止（医疗口径） |
|---|---|
| 黄帝内经/伤寒论等公版古籍学习 | 在线诊断、舌诊、面诊、体质辨识 |
| 古籍原文+项目原创解读 | 处方、治疗方案、疾病预测 |
| 学习笔记、练习题、模拟学习 | 疗效承诺、神效治疗宣传 |
| 经典知识查询 | 「治XX病」类表述 |

- 社区案例：AI舌诊/健康分析报告被要求补「医疗服务-医疗机构」类目 → 本项目**不做**任何AI诊断功能
- 页面用语：知识学习、古籍阅读、学习笔记、练习题、模拟学习、知识整理

## 7. 虚拟支付政策

- 小程序内购买非实物商品（VIP、课程、充值、虚拟内容）→ 虚拟支付业务
- 2026-04-01 起涉及虚拟支付的小程序需全终端接入官方虚拟支付接口
- iOS 端虚拟商品禁止普通微信支付入口
- **本项目决策（与iOS App战略一致）**：微信小程序首版**不开放任何付费功能**（matrix: payment.wechat = OFF）；后续如开放，走微信官方虚拟支付接口

---

## 8. 未成年人保护与隐私

- 强制：《用户隐私保护指引》后台完善（设置-服务内容声明-用户隐私保护指引），逐一声明手机号、文件上传、学习记录、头像等处理场景
- 18岁以下使用需监护人同意机制
- 隐私协议联系方式必须填写（影响隐私接口调用）
- 【后台确认】隐私保护指引中「文件选择」「相册（拍照）」权限项的可用状态
