1. **来源核实**：npm 官方源 `astronomy-engine@2.1.19`，package.json 中 `"license": "MIT"`，homepage 指向 github.com/cosinekitty/astronomy。
2. **商用权限**：MIT 许可证授予复制、修改、合并、出版、分发、再许可及销售权利，仅要求保留版权与许可声明，与本项目商业模式（免费基础 + 按次增值）无冲突。
3. **无限制性资源**：未使用任何 GPL/AGPL/SSPL 或"禁止商用"占星数据包；未使用任何需要按调用计费的星历服务。
4. **版本锁定**：package.json 锁定 `astronomy-engine: ^2.1.19`，运行版本与 toolConfigStore.astro.dataVersion 标识（`astronomy-engine 2.1.19 (MIT)`）一致，前端结果页与免责声明区均展示数据版本。

## 三、物理隔离与可追溯

1. **隔离结构**：第三方库仅存在于 `node_modules/astronomy-engine`，业务代码通过自研封装层 `src/algorithm-core/modules/astro/index.ts` 调用；页面（`src/app/yixue/astro/page.tsx`）不直接 import astronomy-engine，仅使用 algorithm-core 统一导出（calcNatalChart / ASTRO_CITIES / ASTRO_ENGINE_VERSION）。
2. **自研部分**：上升点/天顶换算公式、等宫制宫位划分、相位判定（角度+容许度）、逆行判定（±12h 黄经差分）、星座归属、城市坐标表均为本项目自研，无第三方代码混入。
3. **版本记录**：引擎输出结果中携带 `engineVersion` 字段；用户保存的星盘快照包含引擎版本，历史结果可追溯计算依据。
4. **许可声明**：本清单即为署名与许可记录载体；后续版本升级 astronomy-engine 时须同步更新本清单与 toolConfigStore.astro.dataVersion。
