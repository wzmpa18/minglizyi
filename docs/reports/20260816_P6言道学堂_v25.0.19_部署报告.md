## 二、P6 言道学堂交付明细

### 1. 前端页面（8 页，全部空内容状态可正常访问）

| 页面 | 路由 | 功能 |
|------|------|------|
| 学堂主页 | /academy | 定位说明 + 六宫格入口 + 赛道概览（知识点/题目/我的等级/证书数） |
| 知识学习 | /academy/learn | 赛道筛选 + 知识点展开精读 + 自动学习打卡 + 原文出处 |
| 题库练习 | /academy/question-bank | 赛道×题型双筛选 + 六大题型作答 + 核对答案与解析 |
| 等级考试 | /academy/exam | 赛道/等级选择 → 限时答题（倒计时/超时自动交卷/进度点跳题）→ 成分卡 + 逐题解析 + 证书颁发提示 + 考试历史 |
| 我的证书 | /academy/certificates | 证书卡片（编号/头衔/颁发日/有效期）+ 高级证 2 年复核提示 + 公开验真输入框 |
| 错题本 | /academy/wrong-book | 错题列表 + 展开解析（我的作答/正确答案/解析） |
| 知识工厂 | /academy/factory | 文本/文件双通道上传 + 我的上传列表（状态/分级） |
| 审核工作台 | /academy/factory/review | 管理员密钥 + 资料三审（解析/通过/驳回/定级）+ 知识点审核 + 题目审核 + AI 出题触发 |

### 2. 后端服务（academyRoutes.js @ /api/academy，独立 SQLite academy.db）

- **数据表**：materials / knowledge_points / questions / exams / certificates / study_progress / wrong_answers（7 表独立于用户核心库）
- **流水线**：上传（PDF/TXT/Word/图片/文本）→ AI 解析（章节拆分/知识点提取/标签分类）→ 人工审核（pending 状态不可见）→ AI 出题（六题型/三难度）→ 人工审核 → 入库
- **审核红线**：所有 AI 生成内容 status=pending，必须人工审核通过才对外可见；管理员鉴权 x-admin-key 或 ACADEMY_ADMIN_IDS 白名单
- **组卷规则**：初级 10 题/15 分钟/60 分及格；中级 15 题/25 分钟/70 分；高级 20 题/40 分钟/75 分；按难度配比随机抽题
- **判分**：客观题（单选/多选/判断）全对得分；填空关键词命中比例给分；问答/案例分析给人工评分预留
- **证书**：编号 YA-年份-赛道缩写-序号（如 YA-2026-TCM-000001）；初级/中级永久有效；高级 2 年复核期自动计算 expire_at；公开验真接口免登录
- **AI 通道**：复用 DeepSeek/混元多密钥兼容配置（与 /api/ai/chat 同源），90 秒超时保护
