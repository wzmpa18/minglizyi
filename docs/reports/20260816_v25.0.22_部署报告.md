## 一、本版交付内容（对照 P6-I + P6-J 最终冻结补充指令）

### 1. 五大永久冻结原则的代码落地

| 原则 | 落地实现 | 验证方式 |
| --- | --- | --- |
| 原则1 唯一学习引擎 | 全站仅一套 materials/knowledge_points/questions/exams/certificates 表；中医/易学/国学/机构/私有仅靠 track+category+visibility+org_id 区分 | 库表结构说明（见附录）+ 全场景遍历 |
| 原则2 AI 永久缓存 | ai_call_logs 全量日志表；出题前查 questions.knowledge_id 缓存集合，命中即跳过，0 次 AI 调用 | gen_tasks.skipped_cached 字段实测>0 |
| 原则3 机构 SaaS | organizations/org_members/org_invite_codes/org_earnings 四表 + 机构专区前端页 | 入驻→审核→邀请码→加入→管理全链路 |
| 原则4 三层权限 | materials.visibility(PUBLIC/PRIVATE/ORG) + org_id，上传校验+查询过滤全链路 | PDF/上传拦截实测 + 私有可见性实测 |
| 原则5 学习运营后台 | loc_configs 配置表 + loc_op_logs 留痕表 + /admin/loc 可视化后台页（7 个 Tab） | 配置修改实时生效，无需重启 |

### 2. 用户专项要求

- **上传格式限制**：仅接受记事本类文件 `.txt / .md / .text / .markdown`，PDF/Word/图片一律拒绝
  - 后端：`academyRoutes.js` POST /materials 的 ALLOWED_EXT 白名单
  - 前端：知识工厂上传页 accept 属性 + 选文件即时校验 + 提示文案
  - 实测：`test.pdf` / `notes.docx` / `pic.jpg` 全部返回 400 + 明确报错文案；`verify.txt` 正常入库
- **题目覆盖所有知识点**：新增全覆盖出题引擎（POST /api/academy/questions/generate-full）
  - 遍历类目下**全部**已审核知识点，按 8 个/分组逐组调 AI 出题，每组要求"每个知识点至少 1 道题"
  - 题目逐条绑定 knowledge_id → 覆盖率可量化、可追溯
  - 已有题目的知识点自动跳过（缓存命中，0 消耗）→ 验收铁则"重复生成额度扣减为 0"
  - 覆盖范围说明：针灸穴位/本草药物的"全量"取决于已入库资料内容；系统保证对**库内全部知识点**出题（内容生产属项目方，不属开发边界）

### 3. P6-I 机构学习空间 SaaS

- 后端 12 个机构 API：apply / review / 列表 / 详情 / 邀请码 / 加入 / 成员 / 排行 / 收益 / LOC 全量机构列表
- 前端 `/academy/orgs` 机构专区：机构广场 / 入驻申请（公益|商业） / 我的机构（邀请码·成员·排行·收益弹窗） / 凭码加入
- 收费档位默认值（全部后台可配，不写死）：公益免费 50 人；商业 299/599/999 元每年三档
- 学堂主页新增"机构专区"入口

### 4. P6-J 学习运营中心（LOC）

- 前端 `/admin/loc`（管理员密钥门禁，与审核工作台共用 session 密钥），7 个 Tab：
  1. 数据看板：10 项核心指标 + AI 场景调用统计 + 近 30 天调用趋势
  2. 考试配置：1/2/3 级试卷结构（题量/难度/题型/时长/及格分）可视化编辑
  3. 积分与分佣：5 项积分规则 + 3 项分佣规则
  4. 机构档位：档位增删改（标识/名称/年费/成员上限/权益）
  5. 机构管理：全量机构列表 + 待审核通过/驳回 + 档位配置
  6. 全覆盖出题：任务启动（板块/类目/等级）+ 进度条轮询（每 5 秒）
  7. 操作日志：最近 100 条配置变更（操作人/动作/对象/内容/时间）
- 后端 4 个 LOC API：GET/PUT /loc/config（实时生效）、GET /loc/op-logs、GET /loc/dashboard
- 所有 PUT 自动写 loc_op_logs 留痕；考试组卷实时读取 getExamConfig()

## 五、附录：唯一学习引擎库表说明（验收项1）

```
materials        资料主表（track + category + visibility + org_id 区分五大场景）
knowledge_points 知识点（material_id 关联，全场景共用）
questions        题目（knowledge_id 关联，全场景共用，考试/练习/错题本均从此表抽题）
exams            考试记录（全场景共用判分/补考逻辑）
certificates     证书（全场景共用生成/验真/等级同步）
study_progress   学习进度（全场景共用打卡/解锁）
wrong_answers    错题本（全场景共用）
gen_tasks        全覆盖出题任务（v25.0.22 新增）
ai_call_logs     AI 调用日志（v25.0.22 新增，原则2 可追溯依据）
organizations    机构主表（v25.0.22 新增）
org_members      机构成员（v25.0.22 新增）
org_invite_codes 机构邀请码（v25.0.22 新增）
org_earnings     机构收益（v25.0.22 新增）
loc_configs      运营配置（v25.0.22 新增，原则5）
loc_op_logs      操作留痕（v25.0.22 新增，原则5）
```

不存在任何按板块/机构独立的题库表、考试表、证书表；所有差异仅由 track/category/visibility/org_id 字段表达。
