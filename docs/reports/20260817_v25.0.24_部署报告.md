## 三、Knowledge Hash E2E 验收（模块 2 验收铁则佐证）

**测试设计**：复制资料 #51《中华非遗正骨·颈椎精讲》全文，以不同标题创建测试资料 #55，触发解析。

**实测结果**：

```
API 响应: {"success":true,"dedup":true,"reusedFrom":51,
  "message":"内容指纹命中，直接复用资料#51《中华非遗正骨·颈椎精讲》的知识点与题目，AI 零消耗"}

materials #55: status=parsed, dedup_of=51,
  parse_note="指纹命中：与资料#51内容一致，复用其知识点与题目，本次 AI 调用 0 次"

ai_call_logs id=271: scene=hash_dedup_reuse, tokens_in=0, tokens_out=0
```

**结论**：内容一致的第二份资料 → 指纹命中 → 直接复用 → **AI 额度零扣减**（后台日志佐证）。测试资料已清理，正骨类目保持 15 部。
