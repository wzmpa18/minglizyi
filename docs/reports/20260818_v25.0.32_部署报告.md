## 一、整改内容摘要

按 P7-紫微布局-02 指令，仅整改十二宫内部信息分区、排版与显示优先级，未触碰排盘算法、宫位计算、时间轴、叠宫规则与既有交互。

### 1. 五区布局（同一套布局组件，逐宫统一槽位）

| 区域 | 内容 | 位置 |
|---|---|---|
| A 星曜主区 | 主星/辅星/杂曜（星名+庙旺绑定单元，横排自动换行） | 宫格上部 |
| B 内容缓冲区 | 自动留白，禁止塞入其他文字 | 中部 |
| C 神煞区 | 博士十二神及同类神煞，纵向排列 | 用户视角左下角 |
| D 长生区 | 十二长生 | 右侧靠边 |
| E 动态栏 | 大限/流年/流月/流日/流时/童限/小限动态星 | 右侧动态栏 |

### 2. 关键实现点

- **A 区**：星名字号全盘统一（11px），不因宫位星多缩小；层级仅用颜色/字重/间距区分；每颗星曜与庙旺标识绑定为不可拆分单元（星名在上、庙旺紧贴正下方、同行同基线）；星多时固定字号自动换行并扩展宫格高度，无 `overflow:hidden`、无裁切、无隐藏。
- **C 区**：博士十二神/36 神煞固定左下角、由下向上纵向排列；弱化颜色与字重，字号全盘一致。
- **D 区**：十二长生固定右侧靠边，与 C 区左右分区，统一弱化字号颜色。
- **E 区**：动态星统一「层级前缀+星曜简称」两字形式（大马/流羊/月陀/日禧/时鸾/童禄/小魁…）；显示顺序固定 大限→流年→流月→流日→流时→童限/小限；层级配色：大限蓝 `#2563eb`、流年绿 `#16a34a`、流月青 `#0d9488`、流日深青 `#0369a1`、流时紫 `#7e22ce`、童限琥珀 `#b45309`、小限玫红 `#be185d`；A 区按 E 区实际列数动态预留右侧宽度，区域不互相侵占。
- **童限/小限补齐**：虚岁 < 起运岁 = 童限（童限宫=命宫）；虚岁 ≥ 起运岁 = 小限（宫=ages 表含该虚岁之宫）。此前仅大限/流年有时间层级，本次补齐为七层全量。
- **既有能力零回归**：默认仅本命盘；大限/流年等仅用户主动点击显示；点击大限不自动带出流年；叠宫纵向堆叠两字简称；命宫叠落点加粗下划线；四化算法颜色不变；时间轴/保存/编辑/分享/底部导航不变。
