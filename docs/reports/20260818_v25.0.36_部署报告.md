### 2. 好友点击跳主页、无法发消息（静态导出动态路由 404 根治）

**根因**：Next.js 静态导出对 `/friends/chat/[id]` 等 8 条动态路由仅生成 placeholder 页；真实 ID 跳转时导出目录无对应文件，被 nginx 兜底规则重定向到首页——表现为「点击好友就回主页」。

**修复**：与 `/clients/detail` 同模式，新增 7 张 `?id=` 查询参数静态页 + 7 个 ClientPage 支持 `routeId` prop，全站 19 处跳转点改查询参数：

| 新静态页 | 原动态路由 |
|---|---|
| `/friends/chat?id=` | `/friends/chat/[id]`（好友私聊） |
| `/friends/profile?id=` | `/friends/profile/[id]`（好友主页） |
| `/groups/chat?id=` | `/groups/chat/[id]`（群聊） |
| `/groups/info?id=` | `/groups/info/[id]`（群资料） |
| `/discover/detail?id=` | `/discover/[id]`（动态详情） |
| `/featured/detail?id=` | `/featured/.../[id]`（精选详情） |
| `/zhongyi/yangsheng/detail?id=` | `/zhongyi/yangsheng/[id]`（养生详情） |

### 3. 扫码注册仍要填邀请码

- 注册页读取 `?ref=/?code=`（扫码分享链接已带参）→ **隐藏邀请码输入框**，改显「邀请人已自动绑定 ✓ 注册即与邀请人建立邀请关系，无需填写邀请码」
- 无邀请参数时保持原「邀请码（选填）」输入框
- 下载页文案去除邀请码填写引导

### 4. 附带修复

- profile 二维码弹窗 `qrApiUrl` 未定义运行时崩溃（v25.0.31 遗留）
