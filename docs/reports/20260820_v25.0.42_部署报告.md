## 三、群聊功能修复

### 3.1 Bug 1：群聊页面不可达（用户反馈"不能发信息，不能拉人"）

- **根因**：Next.js静态导出下，动态路由`/groups/chat/[id]`仅生成placeholder页，会话列表跳转`/groups/chat/${groupId}`到真实群ID路径时404
- **修复**：`src/app/friends/page.tsx` 跳转改为查询参数模式 `/groups/chat?id=${groupId}`（`/groups/chat/page.tsx`静态页已存在，正确读取`?id=`复用ClientPage）
- **全项目路由核查**：4处群聊跳转、1处群资料跳转全部统一查询参数模式，无遗漏

### 3.2 Bug 2：管理员无法踢人（用户反馈"需要T人的"）

- **根因**：后端kick接口权限校验仅允许群主（`owner_id !== me`即403），管理员被拒；违反产品需求"群主/管理员均可管理成员"
- **修复**（`backend_deploy/socialApiRoutes.js` + 生产`/www/yandaoguoxue-backend/socialApiRoutes.js`已同步）：
  1. 群主/管理员均可踢人
  2. 管理员不能踢群主（403"不能移除群主"）
  3. 管理员不能踢其他管理员（403"同级保护"，群主可踢管理员）
  4. 被踢者若为管理员同步从admins清除
  5. 被踢者收到`group_kicked`通知（"你已被移出「群名」"）
- **前端一致性**：群资料页成员"管理"按钮按`isManager`（群主/管理员）显示，与服务端权限一致
