## 七、百度收录为 0 的原因说明

**现状**：site:yandao.vip 在百度前台暂搜不到页面。

**原因分析（新站正常现象）**：
1. **新站考察期**：yandao.vip 为 2026 年新注册域名（备案 2026-07 完成），百度对新站有 2-8 周的考察期（俗称"沙盒期"），期间即使提交也不会立即放出收录。
2. **收录放出 ≠ 数据提交**：百度"普通收录"配额已用满（remain:0 表示今日配额 10 条全部推送成功），抓取由百度蜘蛛按自身节奏进行。
3. **前台 site: 查询不稳定**：新站收录初期，site: 查询经常显示 0，但索引量数据在百度搜索资源平台"索引量工具"中会先反映出来。

**当前已就位的全部推进措施**：
| 措施 | 状态 |
|------|------|
| sitemap 提交（百度平台，国学站） | ✅ |
| 每日 API 推送（每站每天 10 条配额，自动） | ✅ 运行中 |
| robots.txt 声明 Sitemap（三站） | ✅ |
| 外链引流（三站互链 + 国学站悬浮回链 + 官网四板块互跳） | ✅ |
| 搜狗/360/必应同步提交（跨引擎曝光增加蜘蛛发现概率） | ✅ |
| IndexNow（必应等即时收录协议，每日自动） | ✅ HTTP 200 |

**预期**：百度收录通常在持续推送 2-4 周后逐步放出，无需额外操作。建议 9 月中下旬在百度搜索资源平台查看"索引量"曲线确认趋势。
