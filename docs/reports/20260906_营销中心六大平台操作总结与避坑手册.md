# 第一部分：总原则（先看这个，避免 90% 的坑）

## 1. 操作顺序铁律

```
正确顺序：先部署验证文件 → 再去平台添加站点 → 验证通过 → 提交 sitemap → API 推送
错误顺序：直接去平台添加 → 验证失败 → 反复排查 → 浪费大量时间
```

**本次最大教训**：360 国学站验证失败，排查后发现是 Nginx 配置里验证文件的 location 块被插到了 HTTP 80 端口（有 301 跳转到 HTTPS），而不是 HTTPS 443 块。**以后所有服务器配置修改，改完必须立即 curl 验证一次，不要等到平台验证失败再回头查。**

## 2. 验证码原则（用户已明确的工作模式）

> 遇到验证码、滑块、点选汉字等人机验证：**立即弹框让用户输入，不要自己反复截图识别。**

本次 360 sitemap 提交时，AI 尝试多次识别验证码失败（"验证码有误~"），最后用户手动输入一次就成功了。**识别一次失败就该交给人**，AI 识别验证码的成功率低且每次尝试都消耗积分。

## 3. 账户登录状态

所有平台用 Edge 浏览器（用户配置文件已保存登录态）。打开方式：
```
msedge.exe --remote-debugging-port=9223 --user-data-dir=C:\Users\ZhuanZ\Projects\minglizyi\tmp\edge-profile
```
- 6 个平台的账户全部已登录，会话长期有效
- 若登录过期，打开对应平台页面，用户会看到登录界面并自行处理

# 第二部分：六大平台逐一复盘

## 平台一：百度搜索资源平台（ziyuan.baidu.com）

### 做了什么
| 项目 | 结果 |
|------|------|
| 站点添加 | www.yandao.vip、国学站、数字管家站均已在账户下 |
| sitemap 提交 | 国学站已提交（69 页） |
| API 推送 | 三站每日自动推送（见自动化章节） |

### 遇到的坑
1. **sitemap 提交配额为 0**：www 站新站没有 sitemap 提交配额（百度对新站限流）。→ 解决：改用 API 推送方式（每日 10 条），效果等价。
2. **"site init fail" 错误**：API 推送 www 站时失败。→ 原因：百度注册的站点格式**不带 https:// 协议头**（`site=www.yandao.vip` 而不是 `site=https://www.yandao.vip`）。修正后成功。
3. **配额说明**：`"remain":0` 表示今日 10 条额度已用完，`"success":10` 表示 10 条全部成功——remain 为 0 不是失败，是正常用完额度。

### 以后最佳操作
- 新页面发布后：把 URL 追加到服务器队列文件（见自动化章节），次日 9:10 自动推送
- 不需要去平台网页操作任何东西，全部走 API

## 平台二：头条搜索站长平台（zhanzhang.toutiao.com）

### 做了什么
三站 sitemap 全部提交成功且已被抓取：
- shuziguajia：28 URL

### 遇到的坑

## 平台三：Google Search Console（search.google.com/search-console）

### 做了什么
| 项目 | 结果 |
|------|------|
| 国学站 sitemap | 提交成功（69 页） |
| 网域资源 yandao.vip | 通过 DNS TXT 记录验证成功，覆盖所有子域 |

### 遇到的坑
1. **资源选择器点击无效**（Google 的 Material 组件 shadow DOM 深）。→ 尝试坐标点击、穿透 shadow DOM、触发 input/change 事件等多种方式，最终放弃页面操作，**改走 DNS TXT 验证**（在腾讯云 DNS 添加一条 TXT 记录）一次成功。
2. **教训**：GSC 的页面自动化非常难，**DNS 验证是唯一可靠路径**——加一条 TXT 记录就完成网域级验证，比逐站文件验证更省事且覆盖全部子域。

### 以后最佳操作
- 新子域名上线：无需任何操作（网域资源自动覆盖）
- 新页面：更新 sitemap.xml 即可，Google 会自动发现
- 收录查询：登录 GSC 看"效果"报告（国内访问需代理，可让用户自己看）

# 第四部分：百度收录为 0 的原因（重要说明）

**现状**：site:yandao.vip 在百度暂时搜不到。

**结论：正常，不是故障。**

1. yandao.vip 是 2026 年新注册域名（备案 2026-07 完成），百度对新站有 **2-8 周考察期**（沙盒期），期间提交了也不立即放出
2. 百度 API 推送配额每天都在用满（success:10/10），该做的都做了
3. 前台 site: 查询在新站初期经常显示 0，但**百度平台后台的"索引量"数据会先涨**——以平台数据为准，不要看前台
4. 三站互链 + 四大引擎（百度/搜狗/360/必应+谷歌）同步提交已全部就位，蜘蛛发现渠道已最大化

**预期**：持续自动推送 2-4 周后逐步放出收录。**期间不需要任何额外操作。**
