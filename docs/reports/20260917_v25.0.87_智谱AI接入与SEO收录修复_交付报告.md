## 一、智谱AI接入（已完成并公网验证）

### 1.1 问题根因：腾讯混元"AI打不开"
服务器日志抓到直接证据：

```
[AI] 空内容返回 finish_reason=length
usage={"prompt_tokens":766,"completion_tokens":8192,
       "completion_tokens_details":{"reasoning_tokens":8192}}
```

**根因**：混元 hy3 是推理型模型，`max_tokens=8192` 被思考（reasoning）全部耗尽，正文为空返回。这是腾讯TokenHub/混元侧的行为，非我方代码bug。
**给您的结论**：如您要继续用混元，需要找腾讯解决（建议方向：hy3 输出 token 上限或思考预算参数）。当前已用智谱替代为主力，不依赖混元。

- 优先级：**智谱 glm-4.5-flash（免费）→ deepseek → 混元**，逐个尝试，全部失败才报错
- 关键参数：`thinking:{type:"disabled"}`（防止智谱同款"思考吃光token"空内容问题）
- `.env` 新增（仅服务器，不入git）：`ZHIPU_API_KEY / ZHIPU_API_URL / ZHIPU_MODEL=glm-4.5-flash`
