## 4. 对象存储结构

- 应用服务器：只保存数据库、清单、权限判断和发布暂存文件。
- 腾讯 COS：私有前缀 `learning-content/offline-packs/...` 保存学习包、图谱与后续音频。
- 客户端：会员登录后由服务器生成 15 分钟短期签名地址，文件流量直接走 COS；下载后执行大小与 SHA-256 双校验，再写入手机持久存储。
- 手机关机/重启后继续使用已经启用的包，不重新下载。
- 发布门禁：包未成功标记为 `deliveryProvider=COS` 时，后台按钮禁用，服务端也拒绝发布。
- 私有对象上传强制 `ACL=private` 与 `Cache-Control: private, no-store`；源码和配置文件不得保存 COS 密钥。

已确认并启用存储桶 `yandao-guoxue-1300262413`（北京地域）。由于存储桶账号与北京 CVM 所属账号不同，无法直接绑定同账号实例角色；改为创建禁止控制台登录的专用 CAM 子用户 `yandao-learning-cos`，仅关联 `learning-content` 学习目录读写、删除、列举及桶 CORS 权限。密钥只写入生产服务器权限为 `600` 的环境文件，没有写入源码、报告或聊天。

三套内容包已发布到私有 COS，生产 Manifest 返回 `totalPacks=3`；匿名下载会员包返回 HTTP 401。每个包均从 COS 签名地址真实下载并通过字节数与 SHA-256 校验，测试对象已清理。

## 5. 用户操作路径

- 学习：首页 → 学习成长 → 中医学习/医考学习/易学学习。
- 本机听学：打开知识点或典籍章节 → 本机听学 → 选择语速 → 开始朗读。
- 离线内容：我的 → 离线内容 → 下载/更新内容包；下载完成后显示“已安装”。
- 分享海报：我的 → 邀请/推广 → 海报 → 学习专区精选海报。
- 管理端：后台 → 离线内容包 → 注册草稿 → 分发到存储桶 → 复核后发布。
