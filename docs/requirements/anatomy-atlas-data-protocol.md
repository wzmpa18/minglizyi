# 三维学习图谱数据协议 1

适用范围：含抽屉全屏查看器及学习资料字段支持的新客户端。旧2129/37及更老内置页面不能仅靠资源包获得新交互。本站网页版可独立部署。这里不授权远程执行代码或隐藏新业务绕过审核。

## 资源与启用

- 使用现有 `/admin/offline-content/`、`/api/admin/offline` 和 COS `learning_content` 分区，包编号 `tcm-anatomy-atlas-v3`。
- 内容为 ZIP：`manifest.json`、`atlas.json`、二进制几何块、`points.json`、`surface.json` 和完整许可通知。
- 清单格式 `yandao-bodyparts-atlas`，`viewerProtocol: 1`，语义版本与每文件大小、SHA-256。
- 外层包 SHA 校验、内层文件 SHA 与协议验证通过后才切换本机索引。失败保留原启用版本。新资源必须提升版本，不复用相同版本替换不同字节。
- 后台注册、分发COS、确认原文件SHA、发布、真实客户端下载回读依次进行。历史资源/许可与一份已验证回退包保留；不能靠登记成功宣称分发完成。
- `publish_tcm_atlas_pack.py` 只针对首个已审核固定SHA，不是任意新包的通用发布授权；后续资料由原受保护内容后台按流程发布。

## 无需新增执行代码的更新范围

- 现有15系统内，兼容二进制布局的模型几何、FJ/FMA概念关系、术语目录。
- `atlas.parts[]` 与 `atlas.concepts[]` 支持可选 `zhName`（中文结构名）、`learningDescription`（学习说明）、`learningSource`（出处文字）。没有字段时保留原名和现有系统概述；不把概述冒充每个结构的专篇。
- 字段仅作React纯文本显示，限制长度；不执行HTML、脚本或通过字段增加权限。
- 经络/穴位名称、同一坐标基准下的工程点位与分段线；审核状态和来源必须随资料维护。几何吸附验证不等于专业定位核校。
- 如更换参考人体，必须重新适配姿势、单位、坐标和点位，不能直接套旧工程坐标；许可也须重审。

## 2026-10-24 模型直接操作

默认全屏，工具与说明收起，穴位覆盖默认关闭。轻点高亮并显示可收起的部位操作；双击同一结构聚焦隔离；原地长按约3秒打开说明与组织操作，拖动、多指与取消不触发。搜索仍可直接聚焦。保持按钮替代路径，不强迫用户记手势。

支持区域观察框（头面、颈、胸、腹、骨盆与髋、左右上肢、左右下肢）、四组显示层、隐藏选中组织、20步有界撤销、恢复全身。区域坐标依据当前参考模型的实际结构范围制定，是工程观察框；框外图元裁切不补造切面纹理。分组显示不等于完整组织学深浅层。双击隔离具体结构时清除区域框，避免把完整器官裁掉。
