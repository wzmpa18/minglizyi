# 三维图谱12B：左侧组织目录与可逆剥离

本专项仅修改言道国学现有图谱交互，复用12A资源3.0.0与协议1。不得调整会员、支付、模型来源或其他产品。

## 操作约定

- 返回键下常驻“组织”按钮；点击或拖动按钮的小把手打开左侧窄栏，不绑定整条系统返回边缘。手机宽度47vw，上限320px；无整屏遮罩。模型画布在剩余区域，保留旋转方向，不重新加载。
- 系统→参考模型区域→真实结构；箭头仅展开，名称选择/聚焦，眼睛显隐，“只看”临时隔离。手机选择结构后默认收起，可固定目录。
- 轻点显示紧凑操作条；资料仍在同一左栏，返回目录保留展开与滚动位置。
- 原地长按500ms隐藏一个来源结构，含其对应全部网格。移动超过8CSS像素、第二指、取消、页面失焦立即终止。默认一次一件；“更多”主动开启连剥后每650ms再剥一件，松手即停。
- 撤销/重做最多30步；恢复隐藏不复位视角；视角复位不恢复隐藏；退出“只看”恢复进入前的显隐/透明/观察参数和镜头。
- 来源FMA器官总成与细分结构共存。例如心脏总成83块网格包含跨系统组织，保留独立动脉目录，不能把跨系统网格误记为新增模型。
- 不具备校对中文名的结构保留英文；区域为模型观察分组，穴位仍为待专业核校的学习示意。

## 验收边界

需分别记录样机、正式Web、Android内置包、Apple内部测试。不得用网站升级替代内置APK升级。现有客户端为打包www，新交互需客户端正常更新；兼容的模型/坐标/说明/镜头参数可由已支持的版本化资料包更新，不能远程执行新代码绕过审核。

真实交付至少包括默认收起、左侧展开、剥离后三张画面，以及开目录→选骨骼→长按剥离→撤销→恢复的录屏。真机未验、临床校核未完、iPhone未验须单列。正式审核继续受原发布门槛约束。
