## 第一步：开启自动快照（最重要，3分钟）

**快照 = 腾讯云帮你每天给整个系统盘拍照片，系统崩了能一键恢复**

1. 打开 https://console.cloud.tencent.com/lighthouse/snapshot
2. 点「自动快照策略」→「新建」
3. 填：
   - 策略名称：`yandao-daily`
   - 执行时间：每天 03:00
   - 保留时间：7 天
4. 关联实例：勾选 `82.156.228.87`
5. 点「确定」

> 完成标志：策略列表里能看到 `yandao-daily`，状态「已启用」

---

## 第二步：开启账号安全（5分钟）

### 2.1 绑定备用手机
1. 打开 https://console.cloud.tencent.com/developer/security
2. 联系手机 → 添加备用手机号
3. 输入第二个负责人的手机号，收验证码绑定

### 2.2 开启 MFA（二次验证，防盗号）
1. 同一页面 → MFA 设备 → 绑定
2. 选「微信扫码」，用微信扫二维码
3. 之后每次登录都需要手机上的动态码

### 2.3 开启登录保护
1. 同一页面 → 登录保护 → 开启
2. 勾选「异地登录需要身份验证」

### 2.4 开启操作保护
1. 同一页面 → 操作保护 → 开启
2. 勾选「销毁实例」「删除快照」等关键操作需二次验证

> 完成标志：安全评分页面显示「您的账号安全评分较高」

---

## 第三步：开启欠费告警（1分钟）

1. 打开 https://console.cloud.tencent.com/expense/alarm
2. 点「新建告警策略」
3. 填：
   - 告警类型：账户余额不足
   - 阈值：余额 < 50 元
   - 通知方式：短信 + 邮件
   - 接收人：勾选主账号 + 备用手机
4. 再建一条：单日消费 > 100 元告警

> 防止：余额不足导致服务器被停，所有数据丢失

---

## 第四步：开启操作审计（2分钟）

1. 打开 https://console.cloud.tencent.com/cloudaudit
2. 点「跟踪集」→「创建」
3. 填：
   - 名称：`yandao-audit`
   - 存储位置：选 COS（如还没 COS 先跳过，回头补）
   - 管理事件：全选（读+写）
4. 点「确定」

> 效果：所有对腾讯云的操作（谁删了快照、谁改了配置）都有记录，不可删除

---

## 第五步：确认云镜安全防护（30秒，只需确认）

1. 打开 https://console.cloud.tencent.com/cwp
2. 确认 `82.156.228.87` 显示「在线」且「防护中」
3. 点「设置」→「告警通知」→ 勾选：
   - 入侵检测告警
   - 漏洞发现告警
   - 异常登录告警
   - 通知方式：短信

> 云镜已经在服务器上跑了，你只需要在控制台确认告警通知开着

## 第六步：跨地域快照（每周一次，手动）

**把北京的快照复制一份到上海，就算北京机房炸了也能恢复**

1. 打开 https://console.cloud.tencent.com/lighthouse/snapshot
2. 找到最新的快照，点「跨地域复制」
3. 目标地域选「上海」
4. 点「确定」

> 建议：每周一早上花 30 秒做一次

## 第七步：开通 COS 对象存储（后续）

**COS = 把备份文件再存一份到上海的云盘，双保险**

前提：需要先获取 API 密钥（访问管理 → API 密钥管理 → 创建密钥）

拿到 SecretId 和 SecretKey 后告诉我，我远程配好 coscmd，之后每天备份自动上传到上海。

COS 开通步骤：
1. 打开 https://console.cloud.tencent.com/cos/bucket
2. 创建存储桶：名称 `yandaoguoxue-backup`，地域「上海」，访问权限「私有读写」
3. 进入桶 → 容错容灾管理 → 开启「版本控制」
4. 同一页 → 开启「回收站」，保留 30 天
